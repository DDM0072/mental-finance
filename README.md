# Mental Finance

App web para trabajar por objetivos: plan semanal, día de pago, metas por saldo y cierre del mes.

- Funciona sin conexión una vez instalada.
- Los datos se guardan solo en el dispositivo (no en este repositorio). Usa **Mi modelo → Respaldo** para exportarlos.

## Instalar en iPhone
1. Abre la dirección de GitHub Pages en **Safari**.
2. Toca **Compartir → Agregar a pantalla de inicio**.
3. Abre la app desde el ícono.
